通联档案管理

这里负责把日常使用的第三方小程序公开记录同步进本站长期档案，也可以手工录入、批量导入和导出备份。管理令牌只保存在当前浏览器会话中。

尚未连接

手工录入

适合补录旧记录或修改已有记录。手工修改后，本站内容优先，不会被后续第三方同步覆盖。

导入历史记录

支持 ADIF、CSV 和 JSON。适合补齐第三方接口已不再提供的较早通联记录，重复数据会自动去重。

同步第三方小程序记录

从 api.mzyyun.com 读取当前可公开查询的近期记录，再保存到本站长期档案。已经归档的旧记录不会因为第三方接口以后不再返回而被删除。

首次同步前，需要在对方小程序的“设置 → 网站接入”中登记本站地址 https://qso.mizuki.top。

导出备份

建议定期导出 JSON 和 ADIF，并在 Cloudflare 之外再保留至少一份副本。

最近记录

用于检查刚刚手工录入、导入或从第三方小程序同步的档案。
